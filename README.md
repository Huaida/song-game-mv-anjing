# 安静 · 还亮着灯的琴房

一首歌，一款可玩的游戏，在游戏里拍 MV。

这是一个可以自由表演并录制的 2D 像素琴房。走动、坐下、起身、开关灯，或者什么都不做。没有评分、规定动作和强制通关。

## 开始游玩

打开网页，或者下载 `play-offline.html` 后用桌面 Chrome 打开。房间可以直接探索。选择电脑上的音频，点击“开始，录一版自己的 MV”：音乐与录像一起开始，音乐结束后回看、保存或重录。默认使用整段音频，也可展开“选取片段”设置起止秒数。

音频只在浏览器里解码、播放和录制，不会上传服务器。此仓库没有内置周杰伦的歌曲录音。

| 输入 | 行为 |
| --- | --- |
| ← → 或 A / D | 左右走动，转身与停留 |
| E 或空格 | 靠近琴凳时坐下；坐着时起身；靠近落地灯时开关灯 |
| C | 切换远景与近景 |

坐着按方向键会先起身再移动。歌曲播放不会代替玩家做动作。灯可以反复开关，不改变录制结束时间。

## 录制与重拍

画面输出 1920×1080，像素画布原生 480×270。游戏通过 Canvas 与 WebAudio 直接把真实画面和正在播放的音乐送入浏览器录制器，不使用麦克风。导出不含按钮、操作说明或录制面板。

新版桌面 Chrome 输出 H.264/AAC MP4。若浏览器不支持可定位回看的 MP4 录制，会明确提示；房间仍可探索。桌面 Chrome 是本次完整验收平台。录制约有 80 ms 启动预滚和 250 ms 编码收尾，选段本身不缩短。保持页面前台；中途结束的录像会明确标记为中断。

录完后可保存操作记录 JSON。它包括版本、音频 SHA-256、选段与初始状态，以及真实按下/松开和镜头输入。点击“按刚才的操作重拍”即可复现；也可重新载入同一音乐和日志重拍。不同音频或游戏版本会被拒绝，避免错误复现。

录制结束以后画面冻结，点击“再录一版”重新开始。示范表演不是标准答案，你可以选择完全不同的节奏。

## 源码

零运行时依赖，无构建要求。`index.html` / `style.css` / `game.js` / `art.js` 可直接放在静态站点。也可以在此目录运行 `python3 -m http.server 8080 --bind 127.0.0.1`，访问 `http://127.0.0.1:8080`。

- `game.js`：固定 60 Hz 世界模拟，音乐时钟，输入日志，录制与回放。
- `art.js`：原创像素布景，整身动作图集，同状态远近镜头。
- `play-offline.html`：与模块版相同代码的独立离线文件。
- `MANIFEST.json`：交付文件 SHA-256。

本次实验只有一个场景，尚未验证多场景切换与手机录制兼容性。
